# Lançamento

App com três telas que passa dados de uma tela para outra usando Intent.

## O que o app faz

- Na tela de lançamento o usuário informa código, quantidade e valor.
- Ao confirmar, os dados são enviados com `putExtra` e exibidos na tela de confirmação.
